# 📊 Análises e Previsões sobre Dados de Cartão de Crédito e Churn

Este repositório contém uma análise detalhada dos dados de cartões de crédito de um banco. 

Este projeto tem como objetivo realizar análises exploratórias e desenvolver modelos preditivos para identificar clientes com maior probabilidade de churn (cancelamento de serviços).

## 🌟 Objetivos do Projeto 
Análise Gráficas dos Dados : Explorar os dados graficamente para buscar correlações entre as variáveis. 
Avaliação e Comparação de Modelos : Avaliar o desempenho dos modelos preditivos com base em métricas como Acurácia, Precisão, Recall, F1-score e AUC-ROC, e comparar os resultados para selecionar o modelo mais eficaz.
Criar um Formulário para Análise de Novos Clientes : No WebApp você pode simular a ação do sistema de previsão de churn inserindo seus dados, o programa irá análisar e te retornar uma resposta positiva ou negativa sobre a aprovação do seu cartão.

## 🛠️ Tecnologias Utilizadas 
- **Python**: Linguagem principal para análise de dados.
- **Pandas**: Manipulação e análise de dados.
- **Matplotlib e Seaborn**: Criação de gráficos e visualizações.
- **Streamlit**: Para desenvolvimento da aplicação web.
- **Render**: Hospedagem do projeto.
- **Scikit-learn**: Criação e avaliação de modelos preditivos.
